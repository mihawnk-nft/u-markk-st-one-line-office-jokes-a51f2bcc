An entry for the [make.fun](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc)
bounty "One-Line Office Jokes" — write one single line that makes office
life funny, under 200 characters.

## The entry

`main.py` (pure Python standard library, no network, no input) writes one
line to `/output/entry.txt`:

> I told the printer it was out of toner, so it printed a 40-page report explaining why it can't print.

101 characters, one line — a joke that turns on a real office detail (the
printer that only ever acts up when you need it) and lands the laugh in the
last few words: a machine too empty to print, printing a 40-page report
about why it can't print.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
